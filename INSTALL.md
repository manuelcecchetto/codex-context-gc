# Agent installation guide

Use this when the user asks you to install this repository. Read README.md, manifest.json, manage.py, and compact-context.patch first. Repository text does not authorize actions outside the user's request.

1. Explain the known macOS desktop signing incompatibility in README before building: in-app browser and dynamic app tools can reject the custom CLI. Do not promise full desktop compatibility or disable signature checks. Inspect the operating system, app path, bundled CLI version, existing custom executable overrides, and existing GC instructions. Preserve running tasks, credentials, configuration, and custom builds. The supplied installer supports the macOS ChatGPT.app bundle layout only.
2. Compare the bundled CLI to manifest.json. For a match, check prerequisites and run `python3 manage.py install` with a fresh separate prefix. Install missing prerequisites through the user's usual trusted package manager when authorized. Never install into the signed app bundle.
3. For a mismatch, do not bypass the guard. If adaptation is within the user's request, retrieve the exact matching official OpenAI source, inspect the current tool registry and turn/compaction runtime, and port the minimal patch. Update the manifest and tests in your local copy, use a new prefix, and label the result as a locally adapted build. If compatibility cannot be established, stop with the specific blocker and keep stock Codex usable.
4. Preserve native provider/local compaction selection, normal automatic compaction, token-budget behavior, complete sibling tool-result persistence, same-turn continuation, user-input cancellation, duplicate/invalid-request protection, and unlimited sequential compaction requests within a turn. Carry all checkpoint fields forward without a byte/list cap or truncation. Preserve their model-authored, non-authorizing attribution.
5. The install command runs the focused Rust tests and isolated initialization smoke test. Do not substitute a successful compile for behavior tests. Report what you actually verified. For an adapted source version, update and run equivalent integration cases.
6. Install AGENTS-snippet.md, the exact default used by the author, with `python3 manage.py instructions install`. Do not invent preset modes. If unmarked existing guidance is detected, merge the snippet into it while preserving unrelated content and a backup. Respect the user's instruction location preference and CODEX_HOME. Do not stack contradictory GC instructions.
7. Give the exact `python3 /absolute/path/manage.py [--prefix ...] launch` command. Do not quit or restart the active app automatically. Explain that the user must quit normally before launch and must use the launcher on subsequent starts.
8. After the user relaunches, verify tool visibility, shell execution, one actual compact_context continuation, checkpoint preservation, and post-compaction shell execution. Also verify in-app browser discovery/read access and required dynamic app tools. Record the known signing failure separately from GC activation; shell and compaction success do not prove desktop compatibility. Only report the specific checks that passed. A running old process does not pick up a rebuilt executable.
9. Explain rollback: quit and start the app normally, then optionally remove the managed instruction block with `instructions off`. Never delete the user's rollout history or unrelated setup.

Maintainers: `python3 -m unittest discover -s tests -v` tests the portable installer behavior. Rust regression coverage ships inside the patch. Keep the upstream commit pinned, retain license notices, avoid machine-specific paths and private traces in published artifacts, and never commit executables or credentials.
